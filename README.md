## ✨ 特色

- **完全在區域網路運作**：程式啟動時會在老師電腦上建立課堂伺服器，不需要 Firebase、雲端帳號或網際網路。
- **學生免安裝**：iPad 用相機掃 QR Code，在 Safari 開啟網頁、輸入名字就能加入。
- **螢幕畫筆**：凍結目前畫面後直接畫記，另有白板、黑板、直線、方塊、圓形、橡皮擦、復原和存檔。
- **截圖出題**：框選畫面任一區域，當作 **塗鴉題／選擇題／簡答題／計算題** 發送給全班。
- **即時儀表板**：學生送出後立即顯示，不需手動重新整理。可放大展示、並排比較，也能一鍵下載。
- **課堂控制**：🎲 從回應中抽人、⏸ 暫停作答、🔁 同一張截圖重新作答。
- **繪圖重播**：在截圖背景上重現學生的作畫過程，可切換 1X／2X／3X 速度。
- **題庫**：課前先截好題目、設定題型並存起來，上課時一鍵派送；可匯出／匯入 ZIP，內含截圖原檔。
- **為觸控大屏設計**：按鈕大、好點，面板可拖曳、收合，並會依螢幕解析度（含 4K）自動調整大小。
- **為 iPad 設計**：截圖全螢幕呈現，支援 Apple Pencil 與手指作畫，也能避免手掌誤觸；工具列可以收合。
- **馬卡龍淡色系**：整體採柔和的現代化介面。

## 💻 系統需求

| 項目 | 需求 |
|------|------|
| 老師電腦 | Windows 10 / 11 |
| Python | 3.9 以上（沒有安裝的話，啟動程式會自動安裝） |
| Python 套件 | `PyQt5`、`qrcode`（啟動程式會自動安裝） |
| 學生裝置 | iPad（Safari），其他有現代瀏覽器的平板、手機、電腦也可以 |
| 網路 | 老師電腦與學生裝置要連在**同一個區域網路／Wi-Fi** |

> 只有**第一次**自動安裝 Python 和套件時需要網際網路，之後上課只需要區域網路。

## 🚀 快速開始

### 方法一：雙擊啟動程式（建議）

1. 下載或 clone 本專案，保持資料夾結構完整（`templates` 資料夾一定要跟主程式放在一起）。
2. 雙擊 **`啟動程式.bat`**。

啟動程式會自動完成以下工作：

1. 尋找電腦上可用的 Python，並自動排除 Microsoft Store 的假 `python.exe` 捷徑。
2. 找不到 Python 時會自動安裝：先試 `winget`，失敗再從 python.org 下載官方安裝檔，以使用者權限安裝，**不需要系統管理員**。
   - 安裝完成後，請**關閉視窗再雙擊一次**啟動程式，讓 Windows 讀到新的 PATH。
3. 檢查並修復 `pip`：依序嘗試 `ensurepip` 和 `get-pip.py`。
4. 缺少套件時自動安裝 `PyQt5`、`qrcode`；如果沒有寫入權限，會改用 `--user` 安裝。
5. 以 `pythonw` 啟動主程式，不會多出黑色命令列視窗。

### 方法二：手動執行

```bash
pip install -r requirements.txt
python 區網版螢幕畫筆_區網互動版.py
```

### ⚠️ 第一次執行：Windows 防火牆

第一次啟動時，Windows 可能跳出防火牆提示，請勾選 **「私人網路」並按「允許存取」**，否則學生的 iPad 會連不進來。
如果不小心按了拒絕，請看[疑難排解](#-常見問題與疑難排解)。

## 👩‍🏫 老師端使用方式

程式開啟後會出現一個**浮動主面板**。開始畫面和畫筆工具都在這個面板裡，可以拖曳上方的「⠿ 螢幕畫筆」移動。

### 主面板（開始畫面）

| 按鈕 | 功能 |
|------|------|
| 伺服器狀態卡 | 顯示伺服器是否運行中、學生連線網址和在線人數 |
| 🖊️ **開始繪圖** | 凍結目前畫面，進入畫記模式 |
| ✂️ **截圖出題** | 不進入繪圖，直接框選畫面出題，出完題自動回到主面板 |
| 📚 **題庫** | 開啟題庫，一鍵派送預先存好的題目 |
| 📱 **連線** | 顯示 QR Code 和連線網址，讓學生掃描加入 |
| 📊 **儀表板** | 開啟即時作答儀表板 |
| 📖 **說明** | 內建使用說明 |
| **A－ / A＋** | 縮小／放大整體介面，設定會記住 |
| 🖥 螢幕選單 | 有多台螢幕時，選擇要在哪一台畫記和截圖 |
| — / ✕ | 最小化／關閉程式 |

### 繪圖模式（按「開始繪圖」後）

面板會原地切換成畫筆工具：

- **畫布**：⬜ 白板、⬛ 黑板；再按一次會回到截圖畫面。
- **工具**：✏️ 畫筆、🧽 橡皮擦、／ 直線、■ 方塊（實心，可以用來遮住答案）、● 實心圓、○ 空心圓。
- **顏色**：10 色。**粗細**：5 種。
- **↶ 復原**（也可以按 `Ctrl+Z`）、**🗑 清除**、**💾 存檔**（存到程式資料夾裡的 `畫記存檔/`）。
- **✂️ 截圖出題**：在畫記過的畫面上框選出題。
- **📚 題庫**：開啟題庫。
- **— 收合**：把面板縮成一條，不擋畫面。
- **❌ 結束繪圖**：回到主面板，同時清除目前的題目。

### 截圖出題流程

1. 按「✂️ 截圖出題」。
2. 在畫面上**拖曳框選**題目範圍，框外會變暗。
   - 要取消的話，按畫面上方的 **「✕ 取消框選」**，或按右鍵、`Esc`。
3. 在出題視窗選擇題型：**🎨 塗鴉題**、**🔤 選擇題**、**📝 簡答題**、**🧮 計算題**。
4. 接著二選一：
   - 按「🚀 發送任務」，全班 iPad 會立即收到。勾選「發送後開啟儀表板」時，儀表板會自動打開。
   - 按「💾 存入題庫」，先存起來、不發送。存入時會使用「題目名稱」欄位的名稱。

> 發送新題目時，上一題的作答會被清空。需要保存的話，請先在儀表板按「⬇ 下載作答」。

## 🧒 學生端使用方式（iPad）

1. 老師按「📱 連線」，學生用 **iPad 相機掃描 QR Code**，或在 Safari 輸入畫面上的網址（例如 `http://192.168.1.23:8000`）。
2. 輸入**名字或座號**，按「加入課堂」。
3. 等老師發題，收到後畫面會自動切換到題目。
4. 作答後按「送出 ✓」。送出後還可以按「✏️ 修改答案」重新作答，老師端只會保留**最新的一份**。

小技巧：

- 在 Safari 按「分享 → 加入主畫面」，之後一點就能開啟，而且會記住名字、自動加入。
- 老師端程式重新開啟後，學生頁面會**自動重新連線**，不用重新輸入名字。
- 連線中斷時，畫面上方會顯示提示並自動重試。

## 📝 題型說明

### 🎨 塗鴉題

- 截圖會**全螢幕**呈現。
- 工具：✏️ 畫筆、🖍️ 螢光筆、🧽 橡皮擦、9 種顏色、4 種粗細、↶ 復原、↷ 重做、🗑️ 全部清除。
- 工具列左邊的「▾」可以**收合**，收合後只剩右下角的「🖌️」和「送出」，再點一次就展開。
- 支援 **Apple Pencil 和手指**：
  - 使用 Apple Pencil 時會暫時忽略手掌觸碰。
  - 手掌先碰到螢幕時，手指仍然可以正常作畫。
- 轉動 iPad 時，已經畫的內容不會跑掉。

### 🔤 選擇題

- 截圖上方顯示題目，下方是 A／B／C／D 四個大色塊，點選後送出。
- 點截圖可以放大檢視。

### 📝 簡答題

- 在輸入框輸入答案（最多 300 字）後送出。
- 點截圖可以放大檢視。

### 🧮 計算題（多頁計算紙）

適合數學題：截圖是題目，學生在計算紙上一步步寫出算式。

- **總覽**：預設四張格線計算紙（2×2），左上角有淡灰色頁碼。
- **頁數不限**：寫到**最後一頁**時，右下角會出現 **「＋ 新增一頁」**（頂列也有 **➕頁**），按下後會新增一張計算紙並直接跳過去（最多 20 頁）。在其他頁時不會顯示新增按鈕；在總覽時，頂列的 ➕頁 會把新頁加在最後。超過 4 頁時，總覽可以上下捲動。
- 點左上角的「題目」縮圖，可以隨時放大看題目。
- **點一格就放大**成滿版書寫板，書寫空間大 4 倍。
  - 左上角「⊞ 回全覽 · 第 N / 總頁數 頁」回到總覽，也可以**兩指捏合**退回。
  - 左右兩側的 ◀ ▶ 可以直接滑到上一頁／下一頁，依頁序循環，不用先退出。
  - 在第 2～4 頁時，上方會出現「👁 看第 N 頁」，可以即時叫出**前一頁的計算**浮動檢視，邊看邊繼續寫。
    - 預覽框可以拖曳標題列移動、按 ⤢ 放大，也能用 ◀ ▶ 翻看更早的頁。
    - 換頁時會自動改為顯示新的前一頁。
- 每寫完一筆，總覽縮圖就會即時同步。
- **工具列**：細筆、粗筆、橡皮擦、4 種顏色、↶ 復原。
  - 🗑️ 清空：會先確認，可選「清除目前這頁」、「清除全部」或「刪除這一頁」。
  - ⬇️ 下載：把所有頁合併成一張 PNG（2 欄排列）；在 iPad 上會開啟分享選單，可以選「儲存影像」存入相簿。
- **Apple Pencil 模式**：偵測到 Apple Pencil 後會自動切換成**只用筆書寫**，頂列會顯示「✍️ 觸控筆模式」，手掌和手指都不會畫出東西。
  - 頂列的「✍️ 觸控筆模式」同時也是切換鈕：點一下切回 **「☝️ 手寫模式」**（手指和觸控筆都能寫），再點一下切回觸控筆模式。手動切換過之後，就不會再被自動切換。
  - 沒有 Apple Pencil 的 iPad，一樣可以用手指書寫。
  - 兩指操作只會用來縮放，不會誤畫。
- 按「送出 ✓」後，老師會收到總覽圖，以及**每一頁的完整解析度圖片**。

## 📊 儀表板

| 區域 | 說明 |
|------|------|
| 頂部 | 目前題型、第幾題、👥 在線人數、✅ 已作答人數，以及下列控制按鈕 |
| ⏸ **暫停作答** | 暫停後學生無法送出答案，iPad 會顯示「老師暫停作答中」；再按「▶ 繼續作答」恢復 |
| 🔁 **重新作答** | 用**同一張截圖、同一題型**讓學生重新作答，原本的作答紀錄會清空（題號不變，標示「重新作答」） |
| 📚 **題庫** | 開啟題庫，直接派送下一題 |
| 📱 **學生連線** | 顯示 QR Code |
| 🎲 **抽人** | 從**已回應的學生**中隨機抽出一位，並顯示他的作答；預設不重複抽，全部抽過後自動重新開始 |
| **作答結果** | 依題型顯示（見下方） |
| **學生名單** | 每位學生的在線狀態（● 綠色表示在線）以及是否已作答；「🧹 移除離線學生」可以清掉已離開的學生 |

依題型顯示的內容：

- **塗鴉題**：作品卡片牆。
  - 點卡片可以全螢幕放大，並用「◀ 上一位／下一位 ▶」逐一展示。
  - 每張卡片可「☆ 選取」，最多 4 張，再按「🔍 比較已選」並排比較。
  - 「⬇ 下載作答」會把所有作品打包成 `.zip`，檔名是學生姓名。
  - **🎬 繪圖重播**：按工具列的「🎬 繪圖重播」，或卡片上的 🎬，會在截圖背景上一筆一筆重現學生的作畫過程。
    - 速度可切換 **1X／2X／3X**（會記住上次的選擇）。
    - 可以拖曳進度條跳到任一時間點，也能用「◀ 上一位／下一位 ▶」依序重播每位學生。
    - 快捷鍵：空白鍵播放／暫停，← → 切換學生。
    - 學生停筆思考的時間會自動縮短（同一筆內最多 0.25 秒、兩筆之間最多 0.6 秒），重播節奏更流暢。
- **計算題**：每位學生一張總覽卡片。
  - 點卡片會開啟「計算過程」檢視，標題會顯示共幾頁。
    - 先看所有頁的總覽：4 頁以內為 2×2，更多頁時改成 3 欄並可捲動。
    - **點任一頁即可單頁放大**。
  - 可用「◀ 上一頁／下一頁 ▶」翻頁，「⊞ 回總覽」回到總覽，「◀ 上一位／下一位 ▶」切換學生；空白頁會標示「（空白）」。
  - 也支援 ☆ 選取並排比較、🎲 抽人。
  - 「⬇ 下載作答」會存成 `.zip`，每位學生一個資料夾，內含 `總覽.jpg` 和每一頁的 `第N頁.jpg`。
- **選擇題**：A～D 長條圖，顯示人數、百分比和選擇的學生；「👁 顯示姓名」可以隱藏姓名，方便投影。
  - 「⬇ 下載作答」會存成 `.csv`，可以用 Excel 開啟。
- **簡答題**：可以切換「🗂 卡片」和「☁️ 文字雲」兩種檢視，相同的答案會合併並放大顯示。
  - 「▶ 逐一展示」可以用大字投影每位學生的答案。
  - 「⬇ 下載作答」會存成 `.csv`。

## 📚 題庫（預先準備題目）

課前先把題目截好、設定好題型，上課時一鍵派送，不用當場截圖。

**新增題目**（任選一種方式）：

- 用「✂️ 截圖出題」框選畫面，選好題型、輸入題目名稱後，按 **「💾 存入題庫」**。
- 在題庫視窗按 **「＋ 截圖新增」**，框選完成後會自動回到題庫。

**題庫視窗的操作**：

| 按鈕 | 功能 |
|------|------|
| 🚀 **派送** | 立即把這題發送給全班；目前正在作答的題目會顯示「📡 派送中」 |
| ◀ ▶ | 調整題目順序 |
| ✏️（或點縮圖） | 修改題目名稱與題型 |
| 🗑 | 刪除題目 |
| ⬇ **匯出 ZIP** | 把整個題庫（含截圖原檔）匯出成一個 ZIP，方便備份或分享給其他老師 |
| ⬆ **匯入 ZIP** | 匯入別人的題庫 ZIP；匯入的題目會**加在現有題目後面**，不會覆蓋 |
| 📂 資料夾 | 開啟題庫資料夾 |

題庫存在程式資料夾的 `題庫/` 裡：

- `presets.json`：題目清單，記錄名稱、題型和順序。
- `images/`：截圖原檔（PNG）。

匯出的 ZIP 也是相同的結構。

## 🔍 介面大小與 4K 螢幕

- 介面會依**面板所在螢幕的解析度**自動調整：
  - 以 1080p 為基準。
  - **4K 螢幕會自動再放大**，在觸控大屏上也清楚好點。
- 把面板拖到另一台螢幕時，會依那台螢幕的解析度重新調整大小。
- 覺得太大或太小，可以在主面板按 **A－／A＋** 微調（80%～160%），設定會記住。

## 🛠 常見問題與疑難排解

**Q：學生掃了 QR Code 卻打不開網頁？**

1. 確認 iPad 和老師電腦連的是**同一個 Wi-Fi／網段**。
2. 確認 Windows 防火牆有允許本程式（Python）使用「私人網路」：
   - 依序開啟「Windows 安全性 → 防火牆與網路保護 → 允許應用程式通過防火牆」。
   - 找到 `Python` 或 `pythonw`，勾選「私人」。
   - 如果電腦目前的網路被設成「公用」，請改成「私人」網路。
3. 電腦有多張網卡（例如同時有有線、無線或虛擬網卡）時，請在「📱 連線」視窗的**網路介面選單**切換其他網址試試。
4. 部分校園 Wi-Fi 會隔離用戶端（AP Isolation），裝置之間無法互連。遇到這種情況，可以改用一台獨立的無線分享器。

**Q：iPad 畫不出來，或偶爾斷線？**

- 請在老師端按「📱 連線」取得網址，在學生 iPad 上**重新整理頁面**，確定載入的是最新版。
- Safari 在背景太久可能暫停連線，回到頁面後會自動重新連上。

**Q：伺服器啟動失敗／連接埠被占用？**

程式預設使用 `8000` 連接埠。被占用時會自動往後找可用的連接埠（最多到 `8019`），實際網址以主面板顯示為準。
如果想固定使用其他連接埠，可以修改登錄檔 `HKEY_CURRENT_USER\Software\PyLanPen\Config` 的 `port` 值。

**Q：啟動程式顯示 Python 安裝完成，但程式沒有開？**

這是正常的：第一次自動安裝 Python 後，請**關閉視窗，再雙擊一次** `啟動程式.bat`。

**Q：套件安裝失敗？**

通常是沒有網路，或 Proxy／防火牆擋住了 PyPI。可以手動執行：

```bash
py -m pip install --user PyQt5 qrcode
```

**Q：畫面上的 emoji 圖示顯示成方框？**

Windows 10／11 內建 Segoe UI Emoji 字型，一般會正常顯示。如果系統字型不完整，只會影響圖示外觀，功能不受影響。

## ⚙️ 技術說明

- **老師端**：Python + PyQt5。以內建的 `http.server`（多執行緒）在 `0.0.0.0:8000` 提供學生網頁和 API，並透過 Qt 訊號即時更新儀表板。
- **學生端**：單一 HTML 檔（純 HTML/CSS/JavaScript，不依賴任何外部 CDN，沒有網際網路也能運作）。
  - 以 Pointer Events 作畫，並用 Canvas 合成截圖與筆跡。
  - 每 1.2 秒輪詢一次題目狀態。
- **QR Code**：由 `qrcode` 套件產生矩陣，再以 Qt 繪製，不需要 Pillow。

### API 一覽

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/` | 學生端網頁 |
| POST | `/api/join` | 加入課堂 `{sid, name}` |
| GET | `/api/poll?sid=` | 取得目前題目版本、題型、是否暫停（`paused`）、是否為重新作答（`retry`），同時更新在線狀態 |
| GET | `/api/mission_image?v=` | 題目截圖（JPEG） |
| POST | `/api/answer` | 送出作答 `{sid, name, type, content, version}`，塗鴉題另附 `replay` 筆畫路徑（圖片座標與時間），計算題另附 `pages`（1～20 頁圖片）與 `empty`（哪幾頁空白）；題目已更新時回傳 `409`，暫停作答時回傳 `423` |

### 其他細節

- 學生超過 6 秒沒有輪詢，就會被視為離線。
- 名字最長 20 字，簡答最長 300 字。
- 題目截圖最長邊壓縮到 1400px；學生塗鴉作品最長邊 1600px（JPEG）。
